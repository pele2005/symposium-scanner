# TRB Symposium – Staff QR Scanner

หน้าสแกนบัตรรับของที่ระลึกสำหรับเจ้าหน้าที่ (เปิดบนมือถือ ใช้กล้องสแกน QR บนบัตร แล้วตัดสิทธิ์ผ่าน Google Apps Script)

- หน้าเว็บ: https://pele2005.github.io/symposium-scanner/
- ตั้งค่า: ใส่ PIN เจ้าหน้าที่ + เลือกช่อง แล้วกดเริ่มสแกน
- ระบบหลัง: Google Sheet "ระบบของที่ระลึก Symposium" + Apps Script (Code.gs) — เก็บใน Box
